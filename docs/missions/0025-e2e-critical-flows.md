## Goal

The critical flows of the PRD are walked through in a real browser on every PR, isolated and with a fake AI provider, and a broken flow blocks the merge.

## Context

PRD roadmap, M7d: 3 to 8 Playwright tests of the critical flows run as a required check, isolated and with a fake AI provider; changing an assertion requires `test-approved`; flaky tests go to quarantine with an issue. This PR is 1 of 4:
1. this one: demo UI, test agents, tests, isolation, `e2e` check;
2. the e2e guard (`test-approved`, healer limited to selectors);
3. flaky quarantine with an issue;
4. exploratory session on request.

The template's demo app had no interface, so this PR adds a minimal one.
